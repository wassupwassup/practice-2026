# Описание проекта
**Название проекта:** Группа проектов игровой индустрии Ascended

**Цель:**  Разработать игру в жанре FPS roguelite с киберпанк-сеттингом, которая продемонстрирует потенциал российских разработчиков.

**Задачи:**
1. Формирование команды проекта и распределение ролей с учётом нового состава разработчиков;
2. Создание технического задания и планирование задач;
3. Разработка концепт-артов персонажей и локаций;
4. Создание систем прокачки персонажа, боевой системы и прочих механик;
5. Создание моделей персонажей, объектов окружения, оружия и локаций;
6. Создание анимаций персонажей;
7. Разработка UI/UX интерфейса.
